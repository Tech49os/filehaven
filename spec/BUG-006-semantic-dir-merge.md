| 优先级 | P1（用户明确举例，且与 BUG-003 共用扫描底座） |

| 测试落点 | `app-v2/src-tauri/src/tests.rs`（归一化 + 批次撤销）；e2e `app-v2/test/e2e-p3.py` 风格新增脚本 |

## 1. 问题陈述

用户原话：「同语义目录合并建议功能缺失：例如 `信科/生产智能化项目组/汇报/月度汇报/2026年9月` 与 `信科/生产智能化项目组/汇报/月度汇报/2026年/9月` 含义完全一致，应该定期的智能识别并给出合并建议。」

现状：`insert_dir` 按 `/` 分隔的物化路径建节点，`2026年9月` 与 `2026年/9月` 是两条合法且不同的 `rel_path`，系统不会识别为同义，更没有合并建议与定时任务。

## 2. 目标 / 非目标

**目标**
- 识别语义等价的目录组（至少覆盖日期层级差异、版本/草稿后缀、空格与全半角差异），给出「A 合并到 B」建议。
- 用户采纳后，把 A 下所有文件按既有 P4 `recategorize` 三段式搬到 B，按批次可撤销，全程可审计。
- 低频、可手动触发的扫描（用户提到「定期」；默认只在手动或启动后低频执行）。

**非目标**
- 绝不自动合并。
- 不在合并时直接删除源目录记录或磁盘空目录（先标记为空，清理另案）。
- 不重复实现 BUG-003 的目录体检框架；本 spec 复用其扫描与建议展示底座，专注「同义组识别 + 合并执行」。

## 3. 行为规格

1. **Given** 目录树中存在 `2026年9月` 与 `2026年/9月`，**When** 同义扫描，**Then** 两者被归为同一候选组，理由写明归一化后的签名与差异点。
2. **Given** 候选组含多个目录，**When** 展示建议，**Then** 推荐保留路径更规范的一方为目标（规则：层级语义更清晰、文件数更多、创建更早），用户可改选。
3. **Given** 用户采纳合并，**When** 执行，**Then** 对源目录下每份文件调用 `recategorize`：复制 → SHA-256 校验 → 旧副本入隔离区；目标同名按 `_2` 错开；写 `migrations.kind='dir_merge'`。
4. **Given** 合并中途某份失败，**When** 批次结束，**Then** 已成功部分保留并记录失败项，用户可单独撤销整批；不得静默跳过失败文件。
5. **Given** 用户撤销合并批次，**When** 执行，**Then** 所有文件的 `archived_path` / `archive_dir_id` 回到合并前；隔离区原件按哈希校验后还原；源目录记录恢复。
6. **Given** 模型不可用，**When** 扫描，**Then** 仍输出确定性规则（日期归一化、后缀剥离）能确认的候选，并标注「未经模型复核」。
7. 扫描过程不得挂进 `refreshBoot()`；须经 `ModelGate` 避让深读队列。

## 4. 变更点

- 新增归一化纯函数（建议 `app-v2/src-tauri/src/dir_norm.rs`）：`signature(rel_path)` 做日期层级归一（`2026年9月` ≡ `2026年/9月`）、版本后缀剥离（复用 `strip_version_suffix`）、全角半角/空格归一；返回可比较签名 + 差异说明。
- 复用 `recommend.rs` 的目录分段词元与覆盖率打分做预筛；模型复核沿用 `suggest_dirs::run` 骨架与 `ModelGate`。
- 合并执行复用 `migration.rs::recategorize` 与 `undo`，新增批次 kind `dir_merge`；前端建议列表沿用 BUG-003 的采纳/忽略交互。
- 合并后源目录标记 `empty` 并保留记录，避免路径悬挂。

## 5. 验收标准（先写红测）

- [ ] Rust 红测：`signature("信科/…/月度汇报/2026年9月") == signature("信科/…/月度汇报/2026年/9月")`。
- [ ] Rust 红测：非同义目录（如 `2026年9月` 与 `2026年10月`）不得归为同组。
- [ ] Rust 红测：两目录各 2 份文件，合并后 `archive_dir_id` 全部指向目标；撤销后逐份还原且 SHA-256 一致；目标同名不覆盖。
- [ ] Rust 红测：模型不可用仍返回规则候选；`ModelGate` 被占用时扫描等待而非抢闸。
- [ ] e2e：构造同义目录 → 手动扫描 → 看到建议 → 采纳 → 浏览页只剩一个目录 → 撤销恢复。

## 6. 风险与边界

- 归一化过度会误合并（`2026年/9月` 与 `9月/2026年` 语义不同）；签名必须保留层级语义，必要时要求人工确认。
- 合并 N 份文件等于 N 次三段式搬移，耗时与失败概率随 N 增长；限制单组文件数（建议 ≤50）并给出进度事件。
- 不碰磁盘空目录删除，避免与隔离区路径约定冲突。
- 建议列表是「建议」不是「命令」，用户忽略后不得再次自动弹窗打扰。
