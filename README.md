# 文件管家 · FileHaven

本地智能文件归档客户端：Windows 桌面 exe，双击即用，文件不出本机。

技术栈已定，未经许可不更换：**Tauri 2 + Rust · Vue 3 + TypeScript + Vite · SQLite；本地模型可选（Ollama）**。

## 能做什么

1. **引导**：选源区（要整理的文件夹）→ 选归档区（建议 D 盘大分区）→ 建目录结构。
   目录结构可让本地模型给两套不同维度的方案，也可以自己写；模型没起就走手动，不阻塞。
2. **整理台**：一次 12 份。`回车` 确认主推、`1/2/3` 选备选、`N` 新建目录、`S` 暂缓、`P` 先放着、
   `↑↓` 换一份、`Ctrl+Z` 撤销。每份都有推荐理由，没有足够像的目录就明确说「待你指定」。
3. **待迁移 → 应用迁移**：按目标目录分组，显示份数与体积；同名自动错开 `_2`，标注后被改过的会红块拦下。
   迁移三段式：复制 → SHA-256 校验 → 源文件入隔离区。搬错了点「撤销这次迁移」逐字节还原。
4. **浏览与查找**：按目录浏览归档区，按文件名 / 正文搜索；图片与扫描件 PDF 可走本地视觉模型解读。
5. **重新归类**：在浏览页右键，归档区内二次迁移；新副本校验后进目标目录，旧副本进隔离区，
   按批次可撤销；已被再次归类的文件在普通批次撤销时自动跳过。
6. **增量监听**：空闲时才做增量整理，系统目录强制黑名单。

## 环境与命令

```bash
cd app-v2
export PATH="$HOME/.cargo/bin:$PATH"
npm install --registry=https://registry.npmmirror.com   # 官方源在本机拉不动
npm run app:dev      # 开发模式（真窗口）
npm run app:build    # 出安装包：src-tauri/target/release/bundle/nsis/
npx vitest run       # 前端 208 例
cd src-tauri && cargo test   # 后端 215 例
```

端到端脚本在 `app-v2/test/`（纯标准库，零第三方依赖），用 `python test/run-e2e.py` 跑完整回归；
日志与隔离数据自动落盘，可随时重建。

| 脚本 | 用处 |
|---|---|
| `run-e2e.py` | p1/p2/p2r/p3 全段回归，落日志 + 时间戳数据目录 |
| `seed-m8.py` | 造真实语料 + 写库；`verify-kill` 核对强杀后标注是否落盘 |
| `e2e-migrate.py` | 迁移/撤销全流程语料与逐字节核对 |
| `cdp.py` | 通过 CDP 驱动 WebView2：读 DOM 文本做断言、发真键盘事件、点击 |
| `shotp.py` | 截窗口成 PNG（BMP 一张 14MB，PNG 只要 90KB） |

> 这台机器上注入的**键盘**事件送不进 WebView2（鼠标能进），所以要用 `cdp.py`：
> 启动前 `export WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=9222"`。

## 硬约定

- 归档根目录固定，扫描全盘但系统目录强制黑名单
- 迁移三段式：复制 → SHA-256 校验 → 源文件入隔离区；永不覆盖、永不直删、可撤销
- 处理范围：文档 + 图片 + draw.io；音视频暂不做
- 仅 Windows
- 模型只做「目录建议」与「视觉解读」，其余全部不依赖模型；模型断开时只有这些能力降级
- 低置信不硬猜，进待确认队列
