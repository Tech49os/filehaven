# 文件管家（本地智能文件归档客户端）

Windows 桌面 exe。技术栈已定，不可更换：**Tauri 2 + Rust · Vue 3 + TypeScript + Vite · SQLite/本地模型（后续）**。

## 硬约定

- 归档根目录固定 `D:\文档归档`，扫描全盘但系统目录强制黑名单
- 迁移三段式：复制 → SHA-256 校验 → 源文件入隔离区；永不覆盖、永不直删、可撤销
- 处理范围：文档 + 图片 + draw.io；音视频暂不做
- 仅 Windows
