# 文件管家 v0.7.0-alpha.1 · 公开测试版

> **这是 alpha 测试版**，功能还在补齐，可能遇到问题。请先看一眼下面的「已知限制」，
> 确认能接受再在自己真实的文件上使用。出问题请到 [Issues](https://github.com/Tech49os/filehaven/issues) 反馈。

一个 Windows 桌面小工具，帮你把堆在桌面、下载、微信文件夹里的文档图片，按内容归到该去的地方。

**所有处理都在你自己电脑上完成，文件一个字节都不会上传。**

### 首次运行会弹「Windows 已保护你的电脑」

这是**正常的**，不是病毒提示。原因是这个项目没有购买代码签名证书（个人项目，证书一年要几千块），
Windows 对任何没签名的 exe 都会这么提示。

绕过方式：

1. 点弹窗里的 **「更多信息」**
2. 出现 **「仍要运行」** 按钮，点它
3. 之后正常使用，不会再弹

如果这一步让你不放心，可以先按上面的方法核对 SHA-256，或者自己从源码编译（见文末）。

## 系统要求

- **Windows 10 1809 及以上 / Windows 11**，64 位
- 系统盘留 200MB（绿色版 + 索引数据库）
- 归档区建议放在空间大的分区（软件会引导你选，默认建议 D 盘）
- 装 WebView2 运行时（Win11 自带；Win10 多数已随 Edge 安装）

本地大模型（Ollama）**不是必需的**。不装也能用全部核心功能，只是「目录建议」和「图片/扫描件解读」会降级——软件会明确告诉你哪些能力不可用，不会静默失败。

## 第一次用，三步

1. **选源区** —— 挑一个你现在最乱的文件夹。第一次别选整个 C 盘，选桌面或下载文件夹就够。
2. **选归档区** —— 文件将来搬去的地方。**建议选一个空文件夹**，别指到已有的资料库里。
3. **建目录结构** —— 可以自己写几个（比如「工作/项目文档」「财务/发票」），也可以让本地模型给两套方案参考。

然后进「整理台」，一次给你 12 份文件，每份都有推荐理由：`回车` 确认、`1/2/3` 选备选、`S` 暂缓、`Ctrl+Z` 撤销。

**不放心就先拿 5 份试试。** 迁移过程随时可以撤销。

## 它怎么保证不弄丢你的文件

这是这个工具最核心的设计，值得说清楚：

**不覆盖、不直删、可撤销。**

每次搬文件都是三段式：

1. **复制** 到目标位置（原文件此时还在）
2. **SHA-256 校验** 新副本和原文件逐字节一致（不一致就中止）
3. 原文件移入 **隔离区**，不是删除

搬错了点「撤销这次迁移」，文件按字节还原回原位。撤销还有两道保险：新副本被人改过会拒绝还原、原位置已经有同名文件也会拒绝——宁可不动，也不覆盖你后来的东西。

删除操作同理，走的是隔离区，代码里**没有任何调用回收站的逻辑**，更没有永久删除。

系统目录（Windows、Program Files 等）是**不可放开的黑名单**，扫全盘也碰不到。

## 已知限制（alpha 阶段）

1. **没有代码签名** — 每次新版本首次运行都会弹 SmartScreen。
2. **窗口没有系统投影** — 为了让窗口边缘干净（去掉了一圈 8px 的透明带），代价是窗口落在桌面上没有 DWM 阴影。
3. **UI 尚未全部完成** — 快捷检索面板分组、部分右键菜单、设置页部分卡片还在做，视觉上会有不一致的地方。
4. **只做了文档 + 图片 + draw.io** — 音视频不处理，会被跳过。
5. **仅 Windows** — mac/Linux 没有计划。
6. **本版只做了冒烟测试** — 没有跑完整的端到端回归，边界场景可能还有问题。
7. **界面动画偏克制** — 低配机器如遇拖动卡顿，去 设置 → 材质效果 关掉毛玻璃。

## 这一版改了什么

相比上一版（v0.6.0-alpha.1），主要变化在界面：

- **Finder 式窗口**：左侧栏从窗口顶部贯通到底，红黄绿灯可点击（关/最小化/最大化），右上角三键删除改成检索胶囊
- **全局毛玻璃**：标题栏 / 侧栏 / 主面板三层模糊半径不同形成纵深，设置页有开关可关掉回退实色
- **目录体检**：自动发现该合并的目录、该改名的文件、空目录，采纳后可整批撤销
- **同义目录合并**：`2026年9月` 和 `2026年/9月` 能认出是同一个
- **整理台删除**：走隔离区，可撤销

另外修了 11 个测试阶段发现的问题，其中两个是窗口本身的缺陷（四角露直角、四周 8px 透明带）。

完整技术细节见 [v0.7.0-alpha.1-发布说明](https://github.com/Tech49os/filehaven/blob/main/bugfix/v0.7.0-alpha.1-发布说明.md)。
