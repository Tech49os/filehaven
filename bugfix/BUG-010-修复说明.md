# BUG-010 修复说明：设置页卡片抗压缩与目录树独立滚动

## 1. 根因

1. **卡片是 flex item 却可被压缩**：`.grid{display:flex;flex-direction:column;overflow:auto;min-height:0}` 中，每张 `<Card>` 默认 `flex:0 1 auto`；而 `Card.vue` 的 `.card{min-height:0;overflow:hidden}`、`.content{min-height:0;overflow:auto}` 正好允许它们被 flex 压扁。目录变多时，7~8 张卡被挤成 14~40px，目录卡内部 `.content` 高 359px / 内容高 3115px，形成「页内滚动 + 卡内滚动」的嵌套滚动，视觉上就是重叠/畸变。
2. **只有体检卡受保护**：BUG-003 加的 `.health-card{flex:0 0 auto}` 只保住首屏入口，其余卡片仍可压缩。
3. **默认全展开放大触发概率**：目录树默认展开全部层级，节点一多就撑爆目录卡。BUG-010 规格要求复用 `collapsedBeyondDepth` 折叠第 3 层及其子节点。
4. **前置事实偏差**：`collapsedBeyondDepth` 实现在独立分支 `bugfix/BUG-002-directory-default-fold`，**并不在当前分支** `bugfix/batch-004-010` 的 HEAD `d1d5afb` 上（`app-v2/src/core/dir-tree.ts` 不存在、Settings.vue 仍是空 `collapsed` 集合）。但 BUG-010 规格第 3 条与红测都依赖它，因此作为本 bug 的依赖补入，未切/并分支。

## 2. 改动清单

仅前端 3 个源文件 + 1 个文档；后端未改，未跑 cargo。

- `app-v2/src/pages/settings/Settings.vue`
  - 新增 `.grid > .card{flex:0 0 auto}`（写法对齐 `PendingMigration.vue:361-370` 的 `.groups`），**所有**直接子卡保持内容高度；**不在 `Card.vue` 全局强制**。
  - 8 张卡统一加 `class="settings-card"` 作为抗压缩标记（红测据此断言）；`health-card` 原有 `flex:0 0 auto` 与首屏位置保持不变（BUG-003 入口不破坏）。
  - `<DirTree>` 外包 `.tree-scroll`，只在这个真正的滚动容器上加 `max-height:min(360px,40vh); overflow:auto; min-height:0`；`min-height:0` 不下放给被压缩子项（项目既有踩坑）。
  - `onMounted` 中 `await dirs.load()` 后套用 `collapsed.value = collapsedBeyondDepth(dirs.tree)`，与树数据同批落位，避免首帧全展开闪烁。
- `app-v2/src/core/dir-tree.ts`（新增）：`collapsedBeyondDepth(nodes, depth=2)`，递归收集 `depth >= 3` 且**有子节点**的目录 id；叶子不进集合。作为 BUG-010 默认折叠依赖补入，未改其它 bug 的逻辑。
- `app-v2/src/pages/settings/Settings.test.ts`：新增 4 项红测（抗压缩 class/样式、目录容器独立滚动样式、默认折叠第 3 层 id、100+ 节点结构不退化 + 体检卡仍是首卡）。happy-dom 无布局引擎，样式断言沿用仓库已有的 `?raw` 源码断言模式，真实几何交给 CDP。
- `bugfix/BUG-010-修复说明.md`（本文档）。

环境：Edge WebView2 + CDP 9222 / dev 5273；`Emulation.setDeviceMetricsOverride` 两档窗口，缩放 100%。选择器全部为全路径，例如 `.grid > .card`、`.grid > .card .tree-scroll`、`.grid > .card .tree-scroll [role="treeitem"]`，几何用 `getBoundingClientRect()` / `getComputedStyle()`，不靠截图像素。

## 4. 边界与遗留风险

- `min-height:0` 只加给 `.tree-scroll`；卡片本身没有它，内容不会溢出画到别的卡片上。
- `Card.vue` 的 `.content{overflow:auto}` 仍在，但卡片现在是内容高度、不参与伸缩，实际滚动只发生在 `.tree-scroll`，因此不会出现嵌套滚动。
- 默认折叠语义：`collapsed` 收录的是**第 3 层有子节点的目录 id**，第 3 层节点本身仍可见，被隐藏的是其第 4 层子节点；与 BUG-002 共用同一策略但两页状态各自独立，不跨页同步。
- 卡片数量实测为 **8 张**（BUG-003 把「目录体检」拆成独立首卡后由 7 变 8）；红测用「≥7」弹性断言，避免把入口可见性改动回退。
- `min()` 在 WebView2 实测生效（280px / 360px 两档），无需回退固定 px + 媒体查询。
- CDP 的 160 节点是运行时注入加压，验证的是 CSS 几何而非后端数据链路；测完已 reload 恢复真实数据。
- 未做截图对照，几何结论以 `getBoundingClientRect` / `getComputedStyle` 数据为准；未改设置项内容/保存逻辑与词表管理。
