# BUG-011 修复说明：全局毛玻璃材质与实色回退（红→绿）

| 项 | 值 |
|---|---|
| 分支 | `bugfix/BUG-011-glassmorphism`（从批次末提交 `edb36ef` 切出，未切分支、未合并） |
| 规格 | `spec/BUG-011-glassmorphism.md` |
| 裁决 | 全局苹果风重做，接受 WebView2 每帧合成成本；保留默认开的关闭开关作低性能设备防御 |
| 提交信息 | `fix(BUG-011): 全局毛玻璃材质与实色回退（红→绿）` |

## 1. 根因

1. `glass.css` 里的 `.glass` / `.glass-panel` 只被自己定义、没有任何组件引用；标题栏、侧栏、主面板、浮层全是实色。
2. `AppWindow.vue` 的 `.win` 用不透明 `var(--c-bg)` 铺满窗口，`App.vue` 的 `body{background:transparent}` 被完全盖住——即使给子节点加 `backdrop-filter`，底下也只有一层纯色，滤镜没有可采样的内容。
3. `tokens.css` / `glass.css` 的注释明确记录「为性能放弃毛玻璃」的旧决策，与本次用户裁决冲突，属于必须推翻的前提。
4. 没有可关闭的材质开关，低性能设备没有任何退路。

## 2. 材质体系

窗口框架分四层，各挂一层半透明材质 + `backdrop-filter: blur(...) saturate(...)`，模糊半径刻意不同形成纵深：

| 层 | 挂载点 | 模糊半径 | 底色 alpha |
|---|---|---|---|
| 标题栏 | `.titlebar.glass-title` | 30px | 0.80 |
| 侧栏 | `.side.glass-side` | 22px | 0.80 |
| 主面板 | `.main.glass-panel` | 16px | 0.82 |
| 浮层（命令面板） | `.panel.glass-float` | 40px | 0.94 |

`.win.glass-frame` 改挂一张多色 CSS 渐变「壁纸」（纯 CSS，不引入图片资源），作为四层 `backdrop-filter` 的共同采样源；`.win` 不再用不透明 `--c-bg` 覆盖底层。浮层用更高不透明度 + 双层阴影，文字下加 `.glass-text` 白底衬。

**列表每一行不接材质**：逐行 `backdrop-filter` 在性能与可读性上双输，「全局风」只做窗口框架层的连贯材质。

材质参数全部集中在 `tokens.css`，唯一调参入口：

```
--glass-blur-title 30px   --glass-blur-side 22px
--glass-blur-panel 16px   --glass-blur-float 40px
--glass-saturate 170%
--glass-bg-title rgba(246,246,248,.8)   --glass-bg-side rgba(242,242,247,.8)
--glass-bg-panel rgba(255,255,255,.82)  --glass-bg-float rgba(255,255,255,.94)
--glass-border rgba(255,255,255,.65)    --glass-text-bg rgba(255,255,255,.84)
--glass-shadow 0 10px 40px rgba(0,0,0,.16), 0 2px 8px rgba(0,0,0,.06)
--glass-bg-win <多色 radial + linear 渐变>
```

## 3. 改动

- `src/styles/tokens.css`：删除旧性能取舍注释，新增上述 `--glass-*` token 与渐变底图；`--c-sidebar/--c-titlebar/--c-bg` 保留为回退实色。
- `src/styles/glass.css`：四层材质规则、`.glass-text` 底衬、浮层阴影；两套回退——`html.no-glass`（用户关闭）与 `@supports not ((backdrop-filter: blur(1px)) or (-webkit-...))`（浏览器不支持），两处规则一致，完整回到实色、无 blur、无叠加阴影。
- `src/components/AppWindow.vue`：`.win` → `glass-frame`，`.titlebar` → `glass-title`；移除 `.win` 的不透明 `background` 与 `.titlebar` 的实色背景/分隔线。
- `src/components/Sidebar.vue`：`.side` → `glass-side`，移除实色背景与分隔线。
- `src/App.vue`：`.main` → `glass-panel`；新增 `watch` 把 `ui.glassEnabled` 映射为 `<html class="no-glass">`（挂在 html 上是因为命令面板 Teleport 到 body，不在 `.win` 子树内）。
- `src/components/SearchPanel.vue`：`.panel` → `glass-float`，`Esc` 与三条提示文字加 `glass-text` 底衬；移除组件内实色背景/边框/阴影，交给全局材质层。
- `src/stores/ui.ts`（新增）：`useUiStore`，`glassEnabled` 默认 `true`，`setGlassEnabled` 写 localStorage 键 `filebutler.glassEnabled`，重启后仍生效。
- `src/pages/settings/Settings.vue`：新增「材质效果」卡片，按钮切换开关，文案说明性能取舍与「列表不用毛玻璃」。
- `src/glass.test.ts`（新增）：11 条源码级契约断言（token、挂载点、底衬、回退、开关持久化）。
- `test/glass-cdp.py`（新增）：可复跑的 CDP 量测脚本（计算样式、对比度、命中测试、三档截图、粗帧率）。
- `--c-text-3` 由 `#6e6e73` 微调为 `#6a6a6f`：玻璃态最坏底图下原值只有 4.30:1，加深后达 4.56:1；与 `--c-text-2` 仍差 11 级灰度，层次不倒挂，字号/尺度 token 未动。

## 7. 性能粗测（不阻断）

CDP `requestAnimationFrame` 1200ms 窗口：**73 帧 / 1207ms ≈ 60.5 fps**。用户已明确接受每帧合成成本，此项仅记录；真机长时间拖动/滚动的掉帧未做压测。

## 8. 边界与遗留风险

1. 持久化采用 localStorage（`filebutler.glassEnabled`）而非 SQLite settings 表：这是纯界面偏好，不依赖 Tauri IPC，便于纯 Vite dev 与 CDP 同代码验证；代价是换浏览器配置目录后偏好不跟随。若产品要求落库，可在 Rust 侧加 `glass_enabled` 键后平滑迁移。
2. 关闭态由 Vue 挂载后写入 `html.no-glass`，首次启动且偏好为「关」时可能有一帧玻璃态闪烁（FOUC）；默认开时无此问题。
3. 侧栏选中项 `.nav.on` 的强调色 `--c-primary #007aff` 叠主色浅底，最坏合成约 3.41:1 —— 这是既有的强调色例外（同 `test/contrast.py` 已登记的 primary 按钮白字 4.02:1），非正文；本次未改品牌色。
4. 材质只在框架层，列表/卡片内部仍为实色，这是刻意的性能与可读性取舍。
5. 真机 e2e 全量回归**未跑**（本轮只做 CDP 定向量测与 vitest/vue-tsc）；BUG-008/009 的字号与尺度断言在全量 vitest 中通过，未发现冲突。
6. `@supports not` 与 `html.no-glass` 两套回退规则手工保持同步；后续改材质参数时需同时检查两处。
