## 二、本次新增

### 1. Finder 式窗口框架（块①）
- 侧栏 **224px 从 y=0 贯通到底**，顶部灯区与侧栏是同一块玻璃，无竖向分割线
- 红黄绿灯 x=22/42/62、12px，**可点击控制窗口**：红=关闭、黄=最小化、绿=最大化/还原
- **删除右上三键**，右上角改为「快速检索 Ctrl K」胶囊（242×30）
- 标题栏只覆盖内容区（x≥224）、高 52px、标题居中 13px

### 2. 全局毛玻璃材质
- 四层模糊半径刻意不同形成纵深：标题栏 **30px** / 侧栏 **22px** / 主面板 **16px** / 浮层 40px，`saturate(1.7)`
- 双回退：设置页「材质效果」开关（默认开）+ `@supports not` 浏览器兜底，关闭后完整回退实色
- 文字对比度 ≥4.5:1；列表每一行**不用**毛玻璃（避免逐行模糊拖慢滚动）

### 3. 目录体检（BUG-003）
- 规则层预筛 `rename/merge/move/empty` 四类，≤20 条按置信度降序
- 模型复核走 ModelGate 非阻塞，不可用时出**降级报告**并标注「未经模型复核」，绝不阻塞
- 采纳后按批次撤销，双保险：新副本被改过拒绝、旧位置有同名拒绝

### 4. 同义目录合并（BUG-006）
- 归一化签名判定：`2026年9月` ≡ `2026年/9月`；版本/草稿后缀剥离；**保留层级语义**
- 复用三段式：复制 → SHA-256 校验 → 旧副本入隔离区；撞名 `_2` 错开
- 按批次撤销，哈希不一致拒绝且不覆盖

### 5. 整理台删除（BUG-007）
- `Delete` 键 / 按钮 → **移入隔离区**，二次确认写明目标路径
- **永不直删、绝不调用回收站**；Ctrl+Z 按批次撤销，字节级还原
- 全链路无「永久删除」字样

### 额外修掉的两个窗口缺陷（块① 收尾）
1. **四角露直角**：`--r-window` 14→**24px**，并让贴边材质层自带对应圆角（带 `backdrop-filter` 的子层不被祖先圆角裁剪，实测 16px 剩 2386 个溢出像素、24px 归零）

## 六、已知边界

1. **窗口无 DWM 投影**：`shadow:false` 消除透明带的直接代价，边缘直接切桌面。缩放能力未丢（保留 `WS_THICKFRAME`）。
2. **真机 e2e 全量未跑**：本版只做了发布包冒烟（窗口框架/材质/入口/窗口灯），`test/run-e2e.py` 的 p1/p2/p2r/p3 全量回归未执行。
3. **UI 块②③ 未做**：Ctrl+K 面板分组细化、右键菜单玻璃化、重新归类二次确认弹窗、安全保证卡/AI 摘要卡、页面大卡圆角 18 等，已在 `spec/PLAN_UI_APPLE_GLASS_v1.md` 排期但不在本版。
4. **材质偏好存 localStorage**：换配置目录后不跟随；首次启动若偏好为「关」可能闪一帧玻璃态。
5. **两套回退规则需同步维护**：`html.no-glass` 与 `@supports not` 各自独立，新增材质规则时两边都要加。

## 七、升级提示

- 从 0.6.0-alpha.1 升级：直接覆盖 exe 或运行安装包；数据库 schema 未变更，无需迁移。
- 本版**不再有窗口投影**，这是有意为之（消除透明边）。
- 老机器如遇拖动掉帧：设置 → 材质效果 → 关闭材质。
