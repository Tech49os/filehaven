## 真实桌面测试（450 文件 / 3.6GB，全程只读）

**第一版引擎在真实数据上灾难性失效**：99% 置信度几乎全分错（差旅单→用户中心、绩效表→支付系统）。根因：词典是电商示例主题（支付/订单/风控），与海油智能工厂业务零重叠；置信度只看分差，泛词偶然命中也给满分。这是"AI 极其确定地搞错"，比不分类危险。

**引擎 v2 重建（classifier.ts 整体重写）**：
- 分类体系改为 **一级工作域 + 二级文档类型**，从真实语料归纳（智能工厂平台/钻采院项目/油化厂项目/部门管理/商务采购/人事培训/财务报销/安全合规/知识沉淀）
- **置信度证据锚定**：无核心证据封顶 0.62 必进待确认；证据只承认文件名里的词；分级 name 0.86+ / body 0.78 / fallback 0.74 / none 0.55
- **正文权重分级**：工作域 0.10（几乎只听文件名，因正文必然罗列各类名词）、类型 0.35；辅助词累加封顶 2.5（防词条多的分类靠堆泛词获胜）
- **"文件名无信息时看正文"降级通道**：final_v2.docx 类文件从 51%(红) 救回 74%(黄)，救回 33 个文件
- **命名改保守策略**：日期前缀 + 保留原名（v1 把差旅单改成"权限_运维手册"，信息全丢）
- 人名压缩包启发式：20 个纯人名 zip → 预填"人事培训/考核人事"但强制待确认
