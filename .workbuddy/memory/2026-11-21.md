1. **迁移后 `files.abs_path` 仍是源区路径**，而源文件已被 `migrate::execute_one` 删掉/移入隔离区
   （`migrate.rs:98` `fs::remove_file(src)`）。所以今天对任何已归档文件点「打开 / 定位 / 预览 / 缩略图」
   都指向不存在的路径。浏览页要能用，必须先落 `files.archived_path` + `files.archive_dir_id`，
   老数据从 `migration_items.dst_path` 按 `archive_dirs.rel_path` 最长前缀回填。
2. `browse_dir` / `search_files` 从 P1 挂到 P2 都没实现（`ipc.ts:229` 有壳，`main.rs:2097` 的
   handler 清单里没有），界面却一直有「浏览」入口 —— 又一次「有壳无后端」。
3. 深读产出的 `topic` 标签只喂了 `tagMatch`，界面（卡片/待定区/浏览）一处都没显示过，
   设计文档 §8.1 画的「标签：安全检查 验收 2026」从未实现。
