   父不再改名，留下空壳 `新名/`。修：磁盘只对最外层 rename 一次。

3. **通用撤销误标 dir_health 批次**：台账 file_id=0 → `migration::undo` 里 `Some(0)` 不跳过 →

4. **忽略态非响应式**：普通 Set 不在 Vue 响应系统内，点「忽略」无视觉反馈。修：改 ref + 整体替换 Set。

**新硬经验（都栽过）**：
- `archived_path` 是**绝对路径**（盘符+反斜杠），前缀替换必须用 `archive_root.join(rel)` 的绝对前缀 +

- Vue 里普通 `Set`/`Map` 不响应式，做「忽略/已选」这种要立刻反馈的标记必须 `ref(new Set())` 且整体替换引用。
- 纯函数测试如果注入假 reviewer，**别让假 reviewer 自行模拟被测逻辑**（如手动打 source=model），
  否则制造假绿；把标记逻辑放被测函数内统一处理，真假 reviewer 走同一路径。
