> 生效范围：`app-v2` 全部界面。本文档是前端实现的**唯一视觉标准**，与效果图 8 张、
> Ardot 画布《文件管家 · Apple 毛玻璃 UI 设计》、`app-v2/src/styles/{tokens,glass}.css` 三方对齐。
> 冲突裁决顺序：本文档 > tokens.css > 旧版《UI设计约束 v1.0》（历史归档）。
>
> 参照物：

## 1. 设计原则（先读这个）

1. **材质只给框架层，不给内容层。** 窗口框架（标题栏 / 侧栏 / 主面板 / 浮层）各一层半透明玻璃；
   卡片、列表行、表格用**实色白**，绝不逐行 backdrop-filter（性能与可读性双输，BUG-011 已裁决）。
2. **模糊半径不同 = 纵深。** 30 / 22 / 16 / 40 四档刻意不同，叠在同一张渐变底图上分层；
   `saturate(170%)` 把底图彩色提出来，产生「透出彩」的苹果质感。
3. **对比度是红线。** 全局正文 ≥ 4.5:1（WCAG AA 小字）。玻璃底色 alpha 一律 ≥ 0.8；
   文字三级灰（#1D1D1F / #5F5F64 / #6A6A6F）是实测达标值，**不许再调浅**。
4. **动效克制有据。** 页面切换 140ms、控件反馈 110~160ms，短、快出、不过度；
   弹簧/回弹/长淡入一律不做。
5. **安全语义优先于美观。** 永不覆盖、可撤销、隔离区这三件事必须在界面上可见
   （安全保证卡、Del 提示、批次说明），不许为了干净省掉。

## 2. 窗口结构（Finder 式，v1.0 新增，待代码落地）

```
┌──────────────────────────────────────────────────┐
│ ● ● ●  │        窗口标题        [ 快速检索 ⌘K ] │ 52px
│────────┘─────────────────────────────────────────│
│ 侧栏    │  内容区（页面标题 + 工具按钮行）        │
│ 224px   │                                        │
│ 贯通到顶│  页面卡片区                            │
└──────────────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 侧栏 | 宽 **224px**，从窗口顶 **y=0 贯通到底**，无断层、无竖向分割亮线 |
| 侧栏顶栏（窗口灯区） | 高 **52px**，材质与侧栏完全相同（同一块玻璃，不是拼上去的） |
| 窗口红黄绿灯 | x = 22 / 42 / 62，y = 20，直径 **12px**，色 `#FF5F57 / #FEBC2E / #28C840` |
| 标题栏 | **只盖内容区**（x≥224），高 52px；窗口标题居中，13px Medium #4B4B50 |
| 右上角三键 | **没有**。最小化/最大化/关闭不出现图标；灯即窗口控制 |
| 全局快速检索 | 内容区右上角，242×30，圆角 10，含 `Ctrl K` 提示；激活态蓝描边 + 10% 蓝底 |
| 窗口圆角 | 24px（效果图）；实现可用 `--r-window: 14px`，取平台安全值 |

**Tauri 落地注意**：对应「自定义标题栏 + 侧栏穿透到顶」布局；窗口灯区域（左侧 84px）必须保留
为系统拖拽区，拖拽热区盖住标题栏与侧栏顶栏整条。

## 3. 四层材质体系（唯一调参入口：tokens.css 的 `--glass-*`）

| 层 | 类名 | 模糊半径 | 底色（白/灰 alpha） | 用在哪 |
|---|---|---|---|---|
| 标题栏 | `.glass-title` | **30px** | rgba(246,246,248, **0.8**) | 内容区顶部条 |
| 侧栏 | `.glass-side` | **22px** | rgba(242,242,247, **0.8**) | 含顶栏，整根贯通 |
| 主面板 | `.glass-panel` | **16px** | rgba(255,255,255, **0.82**) | 内容区底衬 |
| 浮层 | `.glass-float` | **40px** | rgba(255,255,255, **0.94**) | Ctrl K 面板、弹窗、右键菜单 |

公共参数：`saturate(170%)`；描边 `0.5px rgba(255,255,255,0.65)`；
浮层阴影 `0 10px 40px rgba(0,0,0,0.16), 0 2px 8px rgba(0,0,0,0.06)`。

**窗口底图（壁纸）**：不引图片，用渐变给 backdrop-filter 采样——
多枚径向色斑（蓝 0.30 / 紫 0.26 / 橙 0.20）+ `linear-gradient(160deg, #EEF2FB, #F7F4FB 46%, #EEF7F5)`。
效果图中的色斑更柔和（蓝 0.36 blur90 / 粉 0.25 blur100 / 绿 0.20 blur90），实现取 tokens.css 现值即可。

**页面内卡片层级（实色，不用玻璃）**：

| 层级 | 白色 alpha | 圆角 | 阴影 | 例 |
|---|---|---|---|---|
| 主卡 | 0.92~0.94 | 18~20 | `0 12px 28px rgba(18,36,58,0.08)` + 内亮线 | 当前文件主卡、迁移队列、列表面板 |
| 次卡 | 0.88 | 18 | `0 8px 24px rgba(18,36,58,0.06)` | 详情卡、摘要卡 |
| 侧卡 | 0.80 | 18 | 同上 | 本批队列、已确认、目录树 |
| 玻璃浮层 | 0.84~0.94 | 16 | 浮层阴影 + 40px blur | 检索面板、确认弹窗、右键菜单 |

**回退双路径（必须保留）**：① 设置页「材质效果」开关 → `html.no-glass`；
② `@supports not (backdrop-filter)` → 实色。两条路径视觉一致：完整实色、无 blur、无阴影叠加。

## 4. 色彩 token

**主色与功能色**（代码已定，效果图一致）：

| token | 值 | 用途 |
|---|---|---|
| `--c-primary` | `#007AFF` | 主按钮、选中态、链接、进度条 |
| `--c-success` | `#28C840` | 在线点、已归档/已复制（徽章文字用深绿 `#1D7A3D`） |
| `--c-warning` | `#FF9500` | 待定/低置信徽章底（12% alpha）；文字用 `#B25000` |
| `--c-danger` | `#FF3B30` | 隔离区/删除入口、红色徽章 |
| `--c-indigo` | `#575AD8` | AI 相关：摘要卡、标签 chip |

**文字三级**（禁改，对比度已实测达标）：
`--c-text #1D1D1F`（标题/正文主） → `--c-text-2 #5F5F64`（次要/路径） → `--c-text-3 #6A6A6F`（提示/表头）。

**中性色**：底 `#F5F5F7`、字段底 `#F2F2F7`、次按钮底 `#F2F2F7`、分隔线 `#ECECF0`（页面）/ `#E5E5EA`（浮层内）、进度底轨 `#E5E5EA`。

**选中态蓝**：导航/行选中 = 主色 7.5%~10% alpha 底 + 14% 蓝描边 + 文字变 `#007AFF` Medium。

## 5. 圆角 · 阴影 · 字体 · 尺度

**圆角**：浮层/弹窗 16 · 卡片 18~20 · 按钮 11~12 · 字段/选择框 10 · 菜单悬停行 8 · 徽章全圆 13 · 开关全圆。

**字体**：
- 实现 stack：`-apple-system, 'SF Pro Text', 'Segoe UI', 'Microsoft YaHei', 'PingFang SC'`（tokens.css `--font`）
- 效果图用 Noto Sans SC（中文）+ Geist（数字/路径/快捷键）代替，落地映射：Geist → 系统等宽或 SF Mono
- 字号：页面标题 **28 SemiBold** · 卡片标题 16 SemiBold · 区块标题 13~14 SemiBold ·
  文件名 13~15（列表行 Medium）· 正文 12~13 · 次要 11 · 快捷键/路径 11 Regular

**文件条目尺度**（BUG-008 定死，不许缩）：文件名 ≥13 / 次要 ≥12 / chip ≥11 / 行高 ≥1.6；
窄窗走**横向滚动**，绝不缩字号塞 6 列。

**间距**：内容边距 22/24（窄窗 18→14 两档降级，见 tokens.css 媒体查询）；卡片间隙 16；行内 padding 16/12。

**动效**：`--dur-fast 110ms` / `--dur 160ms` / `--dur-page 140ms`，
`--ease-out cubic-bezier(0.22,1,0.36,1)`。悬停/按下 110ms，页面切换 140ms，浮层进出 160ms。

## 6. 组件规范

**导航（侧栏）**：分组标题 11px #6A6A6F；项高 40，圆角 12，图标 20 + 文字 13；
选中 = 蓝 11% 底 + 白 38% 描边 + 文字 #007AFF Medium；右侧数量用 Geist 11；
待定区数量用红色药丸徽章（24×18，白字）。

**按钮三级**：
1. 主按钮：`#007AFF` 实底 + 12 圆角 + 44 高 + 蓝色投影（`rgba(0,122,255,0.20) 0 5px 12px`）+ 白字 13 SemiBold，文案**内嵌快捷键**（如「回车 归到检查报告」）
2. 次按钮：`#F2F2F7` 实底 + 深灰字，同尺寸
3. 玻璃按钮（顶栏工具位）：白 56% alpha + 白 64% 描边，36 高

**徽章**：全圆药丸，语义色 10~12% alpha 底 + 深色文字；状态词固定：
已复制/已归档（绿）、校验中 n%（蓝）、排队中/待定 n%/低置信 n%（橙）、分歧 n%（橙、加粗语义）。

**开关**：30×18 胶囊，开 = `#007AFF`，钮 14px 白，右偏移 2px。

**进度条**：高 4~6，圆角全圆，底轨 `#E5E5EA`，填充 `#007AFF`（校验）/ 主色（显存）。

**右键菜单**：224 宽，玻璃浮层材质（40px blur + 白 92%），圆角 12；
行高 32~34，悬停行 = 蓝实底白字；危险项 `#FF3B30`；右侧快捷键 11px `#8A8A8E`；分组间 1px `#E5E5EA` 线。

**弹窗**：600 宽居中，玻璃浮层材质，背景压暗 14~18%（`#0A0A0C`）；
结构固定：标题 18 SemiBold → 副标 12 → 分隔线 → 内容区 → 分隔线 → 取消（次）+ 确认（主）按钮右对齐。

**Ctrl K 检索面板**：600×~350，浮层材质，输入行 17px + 蓝色 2px 光标；
结果分「最佳匹配 / 目录」两组，选中行蓝 8% 底；底部状态栏：结果数左、快捷键右。

**AI 摘要卡**：indigo 7% 底 + 10% 描边，圆角 13~14，含 AI 星芒图标 + 「AI 摘要」12 SemiBold `#575AD8` + 正文 12；
双路分歧时标题写明「AI 摘要 · 双路不一致」，理由里写模型异议。

**安全保证卡**：success 6% 底 + 10% 描边，标题 12 SemiBold `#248A3D`，行 11px #3A3A3C；
用于迁移页与设置页，内容必须覆盖：撞名错开 `_2`、隔离区可找回、按批次撤销、校验失败自动暂停。

## 8. 落地差异清单（效果图 → 代码，下次开发按此执行）

4. 卡片圆角 18~20 大于 `--r-card 14`：页面级大卡按效果图取 18，控件级沿用 14/10/8。
5. 材质开关、`@supports` 回退、对比度红线全部继承 BUG-011，不回退。
